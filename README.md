# Daniel Marques — Digital Marketing & Strategy Portfolio (2026)

Website interativo de portfólio profissional de **Daniel Marques**, focado em **Marketing Digital, Estratégia de Marca, Social Media e Análise de Performance**.

🌐 **Link do Portfólio no GitHub Pages:** [https://danielffmarques.github.io/](https://danielffmarques.github.io/)

---

## 🚀 Funcionalidades Interativas

- **Índice / Navbar Fixo:** Navegação suave entre secções (*Sobre, Percurso, Ferramentas, Metodologia, Python Lab, Projetos, Contactos*).
- **Simulador Interativo de Campanhas em Python (WebAssembly / Pyodide):**
  - Permite aos visitantes e recrutadores simular orçamentos de tráfego pago (Meta Ads, Google Ads).
  - Executa código Python real no navegador calculando ROAS, CAC, Conversões e Lucro Líquido.
  - Gaveta de código com visualização do script Python fonte.
- **Linha do Tempo Profissional & Académica:**
  - Experiência na **Stream Plan Events** (Ride Across Portugal).
  - Formação na **EDIT.** (17/20) e **IPLUSO** (18/20; Estágio na **Inovcorp** 19/20).
- **Metodologia dos 4 C's:**
  - 01 Análise -> 02 Estratégia -> 03 Execução -> 04 Otimização.
- **Apresentação de Projetos:**
  - **Koenigsegg** (Estratégia e Redes Sociais).
  - **Saoloto Surf School** (Estratégia Go-To-Market).
  - **Brio.** (Plano de Lançamento e Calendário a 90 dias).
- **Contactos Rápidos:**
  - Botão de cópia de email com feedback visual em *Toast*.
  - Link direto para WhatsApp, LinkedIn e download do CV.
- **Suporte a Dark Mode / Light Mode.**

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3 Moderno:** Design responsivo, tipografia com *Plus Jakarta Sans* e *Space Grotesk*, estética Neo-Brutalista com acentos em Tangerine Orange (`#FF5400`).
- **JavaScript (ES6+):** Scrollspy, navegação mobile, filtros de ferramentas e acordeões.
- **Python 3.11 no Navegador:** Powered by **Pyodide (WebAssembly)** para simulação analítica sem necessidade de servidor backend.
- **FontAwesome 6:** Ícones vetoriais.

---

## 📦 Como Testar Localmente

Basta abrir o ficheiro `index.html` diretamente em qualquer navegador moderno, ou utilizar um servidor local:

```bash
# Com Python 3
python -m http.server 8000
```
Acesse: `http://localhost:8000`
